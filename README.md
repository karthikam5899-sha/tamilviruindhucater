# 🍛 Tamil Viruindhu Catering

Modern Tamil Nadu Catering Website built with React + Vite + Tailwind CSS.

## Features

- Responsive homepage
- Sticky navbar with smooth scrolling
- Animated hero section
- About section
- Wedding, corporate, birthday, engagement, house and temple catering
- Tamil Nadu food categories
- Event packages
- Responsive image gallery with hover effects
- Customer testimonials
- Catering booking form UI
- Responsive footer
- Framer Motion animations
- Lucide icons
- Mobile/tablet/laptop/desktop support

## Technology

- React
- Vite
- Tailwind CSS
- Framer Motion
- Lucide React

## Installation

```bash
npm install
npm run dev
```

Open the Vite URL, normally:

```text
http://localhost:5173
```

## Production

```bash
npm run build
npm run preview
```

## Important

The booking form is currently frontend-only. It displays a successful submission state but does not store data in a database or send email/WhatsApp messages.
